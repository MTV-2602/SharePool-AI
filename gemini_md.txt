# Hướng dẫn tích hợp trực tiếp Google Gemini

Bạn có thể gọi và tích hợp trực tiếp các model Google Gemini chính thức (ví dụ: \gemini-2.5-flash\, \gemini-1.5-pro\) thông qua API Gateway 9Router bằng hai cách dưới đây:

---

## 🐍 1. Sử dụng Google GenAI SDK (Thư viện Gemini chính thức)
Cài đặt thư viện chính thức của Google:
\\\ash
pip install google-genai
\\\

Sau đó chạy đoạn mã Python dưới đây. Thiết lập \pi_endpoint\ trỏ về địa chỉ Gateway của bạn:
\\\python
from google import genai
from google.genai import types

client = genai.Client(
    api_key=" \\,
 http_options={\api_endpoint\: \\\}
)

response = client.models.generate_content(
 model=\gemini-2.5-flash\,
 contents=\Xin chào! Bạn là ai?\,
)

print(response.text)
\\\

---

## 🤖 2. Sử dụng OpenAI SDK hoặc cURL tương thích

### Ví dụ Python (Thư viện openai)
Cài đặt thư viện: \pip install openai\
\\\python
import openai

client = openai.OpenAI(
 base_url=\\/v1\,
 api_key=\\\
)

# Gọi trực tiếp model Gemini
response = client.chat.completions.create(
 model=\gemini-2.5-flash\,
 messages=[
 {\role\: \user\, \content\: \Xin chào! Bạn là ai?\}
 ]
)

print(response.choices[0].message.content)
\\\

### Gọi nhanh qua cURL (Terminal)
\\\ash
curl \/v1/chat/completions \\
 -H \Content-Type: application/json\ \\
 -H \Authorization: Bearer \\ \\
 -d '{
 \model\: \gemini-2.5-flash\,
 \messages\: [{\role\: \user\, \content\: \Xin chào!\}]
 }'
\\\

---

## 📡 3. Gọi qua REST API Gemini gốc (cURL)
Bạn cũng có thể gọi trực tiếp Endpoint tương thích định dạng API của Google AI Studio:
\\\ash
curl -X POST \\/v1beta/models/gemini-2.5-flash:generateContent?key=\\ \\
 -H \Content-Type: application/json\ \\
 -d '{
 \contents\: [{\parts\: [{\text\: \Hello!\}]}]
 }'
\\\
